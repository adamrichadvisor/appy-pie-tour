## 1. Executive summary

[Client]'s [application name], built on [technology, e.g. .NET Framework / Oracle Forms / COBOL], supports
[business function] but is increasingly costly and risky to change. We propose a **phased modernization** that begins with a
**2-week assessment** (complimentary / fixed fee) and continues with incremental migration to a modern [cloud / web / mobile]
architecture. Legacy and new modules run side by side, so there is no big-bang cutover.

## 2. Your challenges

- Shrinking pool of people who understand the legacy code
- Slow, risky releases and growing maintenance cost
- Security and compliance exposure from unsupported platforms
- Poor user experience and no mobile access

## 3. Proposed solution

- **AI code comprehension:** automated documentation of code, business rules and data flows.
- **Behaviour-locking tests:** AI-generated regression tests that capture how the current system behaves before we change anything.
- **Strangler-pattern migration:** new services replace legacy modules one at a time behind stable APIs.
- **Modern target stack:** [e.g. .NET 8 / Java 21 / Node, React, Flutter, AWS / Azure / GCP], CI/CD and observability built in.
- **Data migration** with reconciliation reports at every stage.
